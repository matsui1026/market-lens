# 設計

## 1. 構成

```
┌──────────────────────────── あなたの PC ────────────────────────────┐
│                                                                    │
│  ブラウザ (React アプリ)                                             │
│    │  fetch("/api/jquants/…")   ← API キーは持たない                  │
│    ▼                                                               │
│  ローカル中継サーバー (Vite の dev / preview サーバーに組み込み)         │
│    - 127.0.0.1 だけで待ち受け                                        │
│    - Host / Origin / Sec-Fetch-Site を検査し、他サイトからの呼び出しを拒否 │
│    - 許可したエンドポイントとパラメータだけを中継                        │
│    - .env.local の API キーを x-api-key ヘッダーに付ける                │
│    - レート制限（既定 5 回/分）を守るための待ち行列                       │
│    - ページングをまとめて取得                                         │
│    - .cache/ にキャッシュ（あなたの PC の中だけ）                        │
│    │                                                               │
└────┼───────────────────────────────────────────────────────────────┘
     ▼ HTTPS
  api.jquants.com (J-Quants API V2)

  GitHub Pages（公開デモ）: 架空データだけを使う静的サイト。J-Quants には接続しない。
```

### なぜこの構成か

- J-Quants API は、ブラウザから直接呼ぶと CORS のプリフライトが 403 になり、通信できない（2026-10-20 に実測）。
- 運営者側のサーバーで中継すると、J-Quants の規約で禁止されている「運営者側サーバーにデータが蓄積・中継される構成」になる。
- そのため、中継サーバーは利用者自身の PC 上で動かす。

## 2. 画面一覧

| 画面               | パス (hash)         | 目的                                                       |
| ------------------ | ------------------- | ---------------------------------------------------------- |
| ホーム             | `#/`                | 検索欄（起動時にフォーカス）、ウォッチリスト、最近見た銘柄 |
| 銘柄               | `#/stock/:code`     | 株価チャート、基本指標、財務の推移                         |
| 比較               | `#/compare?codes=…` | 最大 4 銘柄の値動きの比較と相関                            |
| このツールについて | `#/about`           | 指標の定義、データの扱い、J-Quants の利用条件、免責        |
| セットアップ       | `#/setup`           | ローカル実行で API キーが未設定のときの手順                |

ヘッダーには、どの画面からも使える検索欄、ナビゲーション、データ取得元の切り替え、テーマの切り替えを置く。

## 3. 最重要フロー

1. アプリを開く（検索欄にフォーカスが当たっている）
2. 「7203」や「トヨタ」と入力する
3. 候補を ↑↓ と Enter（またはクリック）で選ぶ
4. 銘柄画面でチャートと 4 つの指標が表示される

```ts
type Listing = {

type Bar = {
```

J-Quants のレスポンス項目との対応は `src/lib/data/jquantsMapping.ts` に集約する。財務情報は文字列で返り、値がないときは空文字なので、数値への変換と空文字の扱いを 1 か所で行う。

## 5. ブラウザに保存するもの

`localStorage` に保存するのは、J-Quants のデータではない次の設定だけ。

- ウォッチリスト（銘柄コードの配列）
- 最近見た銘柄（銘柄コードの配列）
- テーマ（ライト／ダーク／OS に合わせる）
- データ取得元（デモ／J-Quants）

株価・財務データはブラウザに保存しない（メモリ上のキャッシュのみ）。永続キャッシュはローカル中継サーバーの `.cache/` だけ。

## 6. 指標の定義

| 指標               | 定義                                                                                            |
| ------------------ | ----------------------------------------------------------------------------------------------- |
| 期間騰落率         | 期間最後の終値 ÷ 期間最初の終値 − 1                                                             |
| 年率ボラティリティ | 日次対数リターンの標本標準偏差 × √245                                                           |
| 最大下落率         | 期間中の「それまでの最高値からの下落率」の最大値                                                |
| 平均売買代金       | 期間中の売買代金（調整なし）の平均                                                              |
| 移動平均           | 直近 n 営業日の終値の単純平均（25 日・75 日）                                                   |
| 相関               | 2 銘柄が両方とも取引された日の、日次対数リターンのピアソン相関係数（20 日以上ある場合のみ表示） |

約定がなかった日（四本値が Null の日）は、リターンと指標の計算から除外する。

## 7. エラー状態と表示

| 状態                                | 表示                                                                    |
| ----------------------------------- | ----------------------------------------------------------------------- |
| API キー未設定                      | セットアップ画面へ誘導し、デモデータで試すボタンも出す                  |
| API キー無効（403 invalid）         | 「API キーが無効です」と再設定の手順                                    |
| プラン外（403 その他 / 400 範囲外） | 「ご契約のプランでは取得できないデータです」                            |
| 回数制限（429）                     | 「回数の上限に達しました。約 2 分後に再試行してください」と再試行ボタン |
| 中継サーバーに接続できない          | 「ローカルサーバーが起動していません。`npm start` を実行してください」  |
| J-Quants に接続できない             | 「J-Quants に接続できません。ネット接続を確認してください」             |
| 銘柄が見つからない                  | 「銘柄コード ○○ は見つかりません」とホームへのリンク                    |
| データ 0 件                         | 「この期間のデータはありません」                                        |

## 8. 技術選定

| 領域         | 採用                                        | 理由                                                                       | 採用しなかった候補                                                                                               |
| ------------ | ------------------------------------------- | -------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| UI           | React 19 + TypeScript                       | 型で J-Quants の項目名の誤りを防げる。学習資料が多い                       | Vue / Svelte（大差はないが、作者の学習価値で React）                                                             |
| ビルド       | Vite 8                                      | 高速。dev / preview サーバーに中継処理を組み込める                         | Next.js（サーバー機能が過剰で、静的デモとの両立が複雑）                                                          |
| グラフ       | Apache ECharts 6                            | ローソク足・ヒートマップ・ツールチップ・アクセシビリティ設定が揃う         | Recharts（ローソク足が弱い）、TradingView Lightweight Charts（財務の棒グラフやヒートマップに別ライブラリが必要） |
| データ取得   | TanStack Query 5                            | キャッシュ、重複リクエストの排除、再取得時に前の表示を保つ処理が標準で揃う | 自作フック（バグの温床になる）                                                                                   |
| ルーティング | React Router 8（ハッシュ）                  | GitHub Pages でサーバー設定なしに動く                                      | ブラウザ履歴ルーティング（Pages で 404 対策が必要）                                                              |
| テスト       | Vitest / Testing Library / Playwright / axe | 単体・結合・E2E・アクセシビリティを分担                                    | —                                                                                                                |
| 公開         | GitHub Pages（GitHub Actions でデプロイ）   | 無料。静的デモに十分                                                       | Cloudflare Pages / Vercel（アカウント追加が必要）                                                                |

### 料金

- J-Quants API：Free プラン 0 円（1 年ごとに再登録が必要、12 週間遅延、2 年分、5 回/分）。
- GitHub（公開リポジトリ・Actions・Pages）：0 円。
- サーバー・データベース：なし。

### 変更しやすい部分・しにくい部分

- 変更しやすい：指標の計算（`src/lib/analytics`）、画面のデザイン、対応するエンドポイントの追加（中継サーバーの許可リストに 1 行追加）。
- 変更しにくい：「データは利用者の PC の外に出さない」という前提。クラウドで動かす・共有する機能を追加すると、J-Quants の規約上の扱いが変わる。

## 9. 用語

| 用語         | 意味                                                               |
| ------------ | ------------------------------------------------------------------ |
| CORS         | ブラウザが、別のドメインへの通信を許可されているかを確かめる仕組み |
| プリフライト | CORS の確認のために、本番の通信の前にブラウザが送る問い合わせ      |
| レート制限   | 一定時間に送れるリクエスト数の上限                                 |
| 調整済み株価 | 株式分割などの前後で比べられるよう、過去の株価を補正した値         |
| 対数リターン | ln(今日の終値 ÷ 前日の終値)。足し算で期間のリターンになる          |
| CSP          | ページが読み込んでよいスクリプトや通信先を制限するセキュリティ設定 |
