# 要件定義

## 1. 概要

**Market Lens** は、J-Quants API の株価・財務データを **自分の PC 上だけで** 分析・可視化する、個人学習用の非公式ツールです。

一言でいうと「銘柄コードか社名を入れると、すぐに株価チャートと基本指標が見られるツール」です。

## 2. 解決したい課題

- J-Quants API は JSON を返すだけなので、データを見るたびにコードを書く必要がある。
- 株価の値動きの大きさ（変動率）や下落の深さ（最大下落率）を、定義を理解したうえで自分で確かめたい。
- 複数銘柄の値動きを同じ基準で比べたい。

## 3. 想定ユーザー

| 項目         | 内容                                                                   |
| ------------ | ---------------------------------------------------------------------- |
| 主なユーザー | J-Quants API に個人で登録している学習者（作者本人を想定）              |
| 利用頻度     | 週に数回、調べたいときだけ                                             |
| 利用状況     | PC で集中して使う。スマホ幅でも崩れずに使える                          |
| 技術レベル   | セットアップはコマンドを数回実行できる程度。画面操作は説明なしで使える |

## 4. 最も重要な価値（中心体験）

**アプリを開いたら、検索欄にすぐ入力でき、銘柄を選ぶと 3 秒以内（キャッシュ済み、またはデモ時）に株価チャートと 4 つの基本指標が表示されること。**

- 起動時に検索欄へフォーカスする。登録や説明のポップアップは挟まない。
- J-Quants の Free プランは 1 分間に 5 回までなので、初回取得は待ち時間が出ることがある。その場合は待っている理由を表示する。2 回目以降はローカルのキャッシュから即時に表示する。

## 5. 対応環境

| 項目             | 内容                                                                                                      |
| ---------------- | --------------------------------------------------------------------------------------------------------- |
| 形態             | Web アプリ（ローカル実行）＋ 公開デモ（GitHub Pages）                                                     |
| 最優先端末       | PC                                                                                                        |
| 対応画面         | PC を優先し、タブレット・スマホ幅（360px〜）にもレスポンシブ対応                                          |
| 対応ブラウザ     | 最新の Chrome / Edge / Safari / Firefox                                                                   |
| オフライン       | ローカル実行時は、一度取得したデータをキャッシュから表示できる。デモは読み込み後に通信不要                |
| アクセシビリティ | キーボード操作、フォーカス表示、十分なコントラスト、読み上げ用の表、44px 以上のタップ領域、reduced motion |

## 6. 必須機能

1. **銘柄検索**：銘柄コードまたは社名の一部で検索し、キーボードだけで選べる。
2. **株価チャート**：ローソク足（調整済み株価）、出来高、移動平均（25 日・75 日）。期間は 3 か月／6 か月／1 年／2 年／全期間で切り替えられる。
3. **基本指標**：期間騰落率、年率ボラティリティ、最大下落率、平均売買代金。それぞれ定義を画面で確認できる。
4. **銘柄比較**：最大 4 銘柄の値動きを「期間の初日 = 100」にそろえて比較し、日次リターンの相関を表で見られる。
5. **財務の推移**：通期決算の売上高・営業利益・純利益の推移と、EPS・ROE・自己資本比率の表。
6. **ウォッチリスト**：銘柄を保存し、外したときは元に戻せる。
7. **データ取得元の切り替え**：デモデータ（架空）と、自分の API キーで取得する J-Quants データ。
8. **表で見る**：すべてのグラフに、同じ値を表で確認できる表示を用意する。

## 7. J-Quants の利用規約への対応（必須の制約）

J-Quants の公式ヘルプ「利用目的・ライセンス」に基づき、次の設計を守ります。

- **利用者が各自で J-Quants API を契約し、各自の API キーでデータを取得する構成**にする。
- **取得したデータと分析結果は、利用者本人以外に開示しない**。
  - データの取得・保存は利用者の PC 上（127.0.0.1 で動く中継サーバーとローカルキャッシュ）だけで行う。
  - 運営者側のサーバーで J-Quants のデータを中継・蓄積しない（そもそも運営者側サーバーを持たない）。
  - データや分析結果を共有・公開する機能は作らない。
- **公開デモ（GitHub Pages）には J-Quants 由来のデータを一切含めない**。デモは乱数で作った架空の会社・架空の株価だけを使う。
- J-Quants のロゴは使わない。「公式」「提携」「Powered by」など、J-Quants との関係を示唆する表現は使わない。
- README と画面内の「このツールについて」に、各自が J-Quants API を契約し各自の API キーで取得する構成であることを書く。

参照：https://jpx-jquants.com/ja/help/usage

## 8. 非目標（作らないもの）

- 売買の推奨、売買シグナル、株価予測、「おすすめ銘柄」。投資助言と受け取られる表示はしない。
- ユーザー登録・ログイン・クラウド同期（ローカルで完結するため不要）。
- リアルタイム株価（Free プランは 12 週間遅延）。
- TOPIX との比較（TOPIX 四本値は Free プランでは取得できないため、今回は対象外）。
- データのエクスポート・共有機能（規約上のリスクを避けるため）。

## 9. 仮定（指示に明記がなく、合理的に補ったもの）

| #   | 仮定                                                                                                                              | 理由                                                                                                                                  |
| --- | --------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| A1  | アプリ名は「Market Lens」                                                                                                         | 指定がなかったため。JPX や J-Quants の名称は製品名に含めない                                                                          |
| A2  | 利用者は Free プランを想定し、レート制限は既定で 1 分間に 5 回                                                                    | 有料プランの人は設定で変更できる                                                                                                      |
| A3  | 株価は調整済み株価（分割・併合を考慮）を使う                                                                                      | 分割をまたぐ期間でもチャートと指標が連続するため                                                                                      |
| A4  | 年率換算は 1 年 = 245 営業日                                                                                                      | 日本の年間営業日数に近い値。画面と README に明記する                                                                                  |
| A5  | 移動平均は 25 日・75 日                                                                                                           | 日本で一般的な設定                                                                                                                    |
| A6  | 財務は通期決算短信（DocType に `FYFinancialStatements` を含み、CurPerType が `FY`）を使い、同じ決算期は開示日時が最新のものを採用 | 訂正開示を反映するため                                                                                                                |
| A7  | 認証（ログイン）は作らない                                                                                                        | データが利用者の PC の外に出ない構成のため、守る対象がない。中継サーバーは 127.0.0.1 だけで待ち受け、他サイトからの呼び出しを拒否する |
| A8  | 公開範囲は「GitHub リポジトリ（公開）＋ GitHub Pages（デモのみ）」                                                                | ユーザーの指示「GitHub とかで公開まで完了」に基づく                                                                                   |
| A9  | 言語は日本語 UI のみ                                                                                                              | 想定ユーザーが日本語話者のため                                                                                                        |

## 10. 受け入れ条件

- [ ] デモで、検索 → 銘柄選択 → チャートと指標の表示までが、キーボードだけでもマウスだけでも完了する。
- [ ] 期間を切り替えると、チャート・指標・表がすべて同じ期間で再計算される。
- [ ] 比較画面で 2〜4 銘柄を追加・削除でき、削除は元に戻せる。
- [ ] ウォッチリストへの追加・削除・元に戻すが動き、再読み込み後も保持される。
- [ ] 存在しない銘柄コード、空の検索、通信失敗、API キー未設定、API キー無効、回数制限（429）で、次に何をすればよいかが分かるメッセージが出る。
- [ ] ローカル実行時、API キーがブラウザ側のコード・通信・画面・ログに出ない。
- [ ] 中継サーバーが、許可したエンドポイント以外・不正な銘柄コード・他サイトからのリクエストを拒否する。
- [ ] スマホ幅（375px）・タブレット幅・PC 幅でレイアウトが崩れない。
- [ ] axe による自動アクセシビリティ検査で重大な違反がない。
- [ ] reduced motion でアニメーションが止まり、操作は成立する。
- [ ] lint・型チェック・単体テスト・ビルド・E2E テストがすべて通る。
- [ ] GitHub に公開され、GitHub Pages のデモ URL で上記の主要フローが動く。
