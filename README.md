# Market Lens

J-Quants API の株価・財務データを、**自分の PC 上だけで**分析・可視化する、個人学習用の非公式ツールです。
銘柄コードか社名を入れると、株価チャートと基本指標（騰落率・ボラティリティ・最大下落率・売買代金）を表示します。

- **公開デモ（架空データのみ）**: https://matsui1026.github.io/market-lens/
- デモは乱数で作った架空の 10 社（DM01〜DM10）だけを表示します。J-Quants には接続しません。

> 本ツールは日本取引所グループおよび J-Quants とは関係のない非公式のツールです。表示内容は学習用で、投資助言や売買の推奨ではありません。

## 機能

| 機能           | 内容                                                                                   |
| -------------- | -------------------------------------------------------------------------------------- |
| 銘柄検索       | コード・社名（全角/半角、ひらがな/カタカナを区別しない）。キーボードだけで操作可能     |
| 株価チャート   | 調整済み株価のローソク足（陽線は白抜き・陰線は塗りつぶし）、出来高、25日・75日移動平均 |
| 期間           | 3か月 / 6か月 / 1年 / 2年 / 全期間。チャート・指標・表がすべて連動                     |
| 基本指標       | 期間騰落率、年率ボラティリティ、最大下落率（期間付き）、平均売買代金                   |
| 業績の推移     | 通期決算の売上高・営業利益・純利益（直近 5 期）と、EPS・ROE・自己資本比率の表          |
| 銘柄比較       | 最大 4 銘柄を「初日 = 100」にそろえて比較。指標の比較表と、日次リターンの相関表        |
| ウォッチリスト | 追加・削除・元に戻す。ブラウザに銘柄コードだけを保存                                   |
| 表で見る       | すべてのグラフに同じ値の表を用意（読み上げ・色覚の多様性に対応）                       |
| 表示           | ライト / ダーク / OS に合わせる、スマホ幅対応、reduced motion 対応                     |

指標の定義はアプリ内の「このツールについて」と [docs/DESIGN.md](docs/DESIGN.md) にあります。

## J-Quants の利用条件とデータの扱い

J-Quants API は個人の私的利用に限ったサービスです（[利用目的・ライセンス](https://jpx-jquants.com/ja/help/usage)）。このツールは、同ヘルプが示す条件に沿って設計しています。

- **各ユーザーが自分で J-Quants API を契約し、自分の API キーでデータを取得する構成です。** このリポジトリの作者がデータを配信・中継することはありません。
- 取得したデータと分析結果は、**利用者本人以外に開示されません**。
  - データの取得は、利用者の PC で動くローカルサーバー（`127.0.0.1` のみで待ち受け）が行います。
  - 取得データは利用者の PC の `.cache/` にだけ保存され、外部に送信されません（Git にもコミットされません）。
  - データや分析結果を共有・公開する機能はありません。
- 公開デモ（GitHub Pages）には J-Quants 由来のデータを一切含めていません。
- プランの解約・ダウングレード後は `npm run cache:clear` で保存データを削除してください。

## 必要なもの

- Node.js 22.12 以上（推奨: 24 LTS）
- J-Quants API のアカウントと API キー（Free プランで利用可）

## セットアップと起動

```bash
git clone https://github.com/matsui1026/market-lens.git
cd market-lens
npm ci
npm run setup     # API キーを貼り付け（入力は表示されません）、プランを選択
npm start         # ビルドして http://127.0.0.1:4173 で起動
```

- `npm run setup` は API キーを `.env.local`（Git 管理外）に保存し、最後に接続確認（`npm run check:api` と同じ）を行えます。
- `npm run check:api` は、API キーが有効か、各エンドポイントがアプリの想定する項目を返すかを確認します。データの中身やキーは表示しません。
- 開発中は `npm run dev`（http://127.0.0.1:5173）を使えます。
- API キーを設定しなくても、画面右上で「デモ」に切り替えれば架空データで試せます。

`npm run setup` が使えない環境では、`.env.example` を `.env.local` にコピーして値を書いてください。

## 環境変数（`.env.local`）

| 変数                         | 必須   | 説明                                                                            |
| ---------------------------- | ------ | ------------------------------------------------------------------------------- |
| `JQUANTS_API_KEY`            | はい   | J-Quants のダッシュボード（設定 » API キー）で発行した API キー                 |
| `JQUANTS_RATE_LIMIT_PER_MIN` | いいえ | 1 分あたりのリクエスト上限。Free=5（既定）, Light=60, Standard=120, Premium=500 |

`VITE_` で始まる変数はブラウザ側のコードに埋め込まれるため、API キーには絶対に使わないでください（ビルド時に検査して停止します）。

## 技術構成

| 領域                     | 採用                                                           |
| ------------------------ | -------------------------------------------------------------- |
| UI                       | React 19, TypeScript 6, React Router 8（ハッシュルーティング） |
| データ取得               | TanStack Query 5                                               |
| グラフ                   | Apache ECharts 6（SVG レンダラー）                             |
| ビルド・ローカルサーバー | Vite 8（dev / preview サーバーに J-Quants 中継処理を組み込み） |
| テスト                   | Vitest, Playwright, axe-core                                   |
| 公開                     | GitHub Actions → GitHub Pages（デモのみ）                      |

```
ブラウザ (React) ──/api/*──▶ ローカル中継 (127.0.0.1, Vite に組み込み) ──x-api-key──▶ api.jquants.com
                                 │ 許可したエンドポイントのみ / Origin 検査 / レート制限 / ページング
                                 └─ .cache/ （あなたの PC 内のキャッシュ）
```

J-Quants API はブラウザから直接呼ぶと CORS のプリフライトが拒否されるため、利用者の PC 上の中継を使います。詳しくは [docs/DESIGN.md](docs/DESIGN.md)、要件と仮定は [docs/REQUIREMENTS.md](docs/REQUIREMENTS.md)、テスト結果は [docs/TEST_REPORT.md](docs/TEST_REPORT.md) を参照してください。

## セキュリティ

- API キーは `.env.local` にのみ保存し、ブラウザ・ログ・エラーメッセージに出しません（自動テストで確認）。
- ローカル中継は `127.0.0.1` で待ち受け、Host / Origin / Sec-Fetch-Site を検査して他サイトからの呼び出しを拒否します（DNS リバインディング対策を含む）。
- 中継できるのは 3 つのエンドポイント（上場銘柄一覧・株価四本値・財務情報）だけで、銘柄コードは形式を検査します。
- ビルドしたページには Content-Security-Policy を設定し、外部のスクリプト・通信を禁止しています。
- API の接続先を差し替えられるのはテスト用のループバックアドレスだけで、キーが外部に送られることはありません。

## 公開（GitHub Pages）

`main` へのプッシュで GitHub Actions が検査・テストを行い、成功するとデモ版（`dist-demo/`）を GitHub Pages に公開します。初回のみ、リポジトリの Settings » Pages で Source を「GitHub Actions」にしてください。

## 既知の制限

- Free プランのデータは約 12 週間遅れで、取得できるのは約 2 年分です。初回表示は 1 分間 5 回の制限で待ち時間が出ることがあります（2 回目以降はキャッシュから表示）。
- TOPIX など指数との比較は、Free プランで指数を取得できないため未対応です。
- 配当による株価調整は含みません（J-Quants の調整済み株価の仕様）。
- 実際の J-Quants API（Free プラン）での動作は確認済みです。有料プランでの長期間データ・Safari / Firefox は未確認です。
